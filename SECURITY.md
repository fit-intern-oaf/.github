# Security policy

OpenAIFlex is a research project working with electrical-grid data and
control-adjacent interfaces. We take security reports seriously.

## Reporting a vulnerability

**Do not open a public GitHub issue for security problems.**

Report via one of the following:

1. **GitHub private vulnerability reporting** on the affected repository
   (Security tab → Advisories → Report a vulnerability). Preferred.
2. Email: `pranav.jayant.kulkarni@fit.fraunhofer.de` (Fraunhofer FIT project
   lead). PGP key available on request.

Please include:

- Repository and version affected.
- Steps to reproduce.
- Impact assessment (confidentiality, integrity, availability).
- Any proposed mitigation.

## Response targets

| Severity | Acknowledgement | Fix available |
|---|---|---|
| Critical (RCE, auth bypass, data exfiltration) | 2 business days | 10 business days |
| High | 5 business days | 20 business days |
| Medium / low | 10 business days | best-effort |

We will coordinate disclosure with the reporter. Default embargo is 90 days
from first acknowledgement.

## Scope

In scope: all repositories under `github.com/openaiflex`, including forks.

Out of scope:

- Vulnerabilities in upstream dependencies — report those upstream; we track
  advisories via Dependabot and will patch in our forks accordingly.
- Vulnerabilities in partner-operated infrastructure (DANTE, RomeFlex,
  Austrian DSO SCADA, etc.) — report to the operating partner.

## Supply-chain integrity

Every released container is:

- SBOM-attached (SPDX JSON, generated by syft, attached as a GHCR artefact);
- Signed with cosign using GitHub OIDC keyless signing;
- Scanned by Trivy on build and weekly.

Verify a release image:

```bash
cosign verify \
  --certificate-identity-regexp 'https://github.com/openaiflex/.*' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  ghcr.io/openaiflex/<image>:<tag>
```
